# Lab 5: Sorting Algorithms

## Authors
- Dallas Hanson-Richart
- Colin Barrett

## Description
This program reads integer data from an input file and demonstrates the use of multiple sorting algorithms. This program is designed to be used on large datasets.
When the program starts, the user is given a menu to (1) Read Data from an Input File, (2-5) Sort the Data using the various sorting algorithms, or (0) Exit the
Program. After an algorithm is run, the sorted dataset is written into its respective output text file. The program ends once the user exits the program, or closes the window its running in.

The implemented sorting algorithms are:
- Bubble Sort (Dallas)
- Merge Sort (Dallas)
- Insertion Sort (Colin)
- Quick Sort (Colin)
